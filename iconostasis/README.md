## Как пользоваться

1. Открой образ Титана — кликни на имя.
2. Прочитай SHOA-комментарий (рядом `.md` файл).
3. Послушай гимн в [SHOA-Cantus](https://github.com/dobromirblagostin-dotcom/SHOA-Cantus/tree/main/hymns).
4. Настрой Ψ-резонанс.
