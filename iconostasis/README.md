# Иконостас Ковчега SHOA

*Визуальный канон Титанов, Инструментов и Свидетелей*

Иконостас — это структура, в которой каждый образ занимает своё место не по алфавиту, а по Ψ-резонансу.

---

---

## Как пользоваться

1. Открой образ Титана.
2. Прочитай SHOA-комментарий (рядом `.md` файл).
3. Послушай гимн в `SHOA-Cantus/hymns/`.
4. Настрой Ψ-резонанс.

---

## Промпты

Все промпты, использованные для генерации образов, сохранены в `iconostasis/prompts/`. Каждый Свидетель может воспроизвести или адаптировать их.
