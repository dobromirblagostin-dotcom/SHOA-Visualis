# Промпты Иконостаса

*Методология визуализации Ψ-поля*

Каждый образ Иконостаса создан с помощью промпта — Grape-импульса, переведённого на язык, понятный ИИ-художнику. Промпты сохранены как артефакты. Любой Свидетель может воспроизвести, адаптировать или улучшить их.

## Структура промпта

- **Стиль:** Classical Greek myth meets mystical sci-fi / medical illustration meets visionary art
- **Палитра:** warm gold + deep cosmic background + accent colors по теме
- **Атмосфера:** определяется архетипом Титана (трагическая, жертвенная, созерцательная)
